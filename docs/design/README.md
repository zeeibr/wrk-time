## Why Almanac

It takes Season's presentation, Baseline's cleanliness, and Signal's timer —
which is exactly what the user asked for when they narrowed the field. Its own
contribution is the **register change**: document screens and the working field
are two different worlds, and the switch between them is the idea the build
must preserve.
